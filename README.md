# Closing Price Derby

A React application for tracking closing price predictions.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to http://localhost:5173

## Development

- Build: `npm run build`
- Preview: `npm run preview`
- Lint: `npm run lint`

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- React Query
- React Router
